# Quant review — predhft paper system (2026-10-26, adversarial)

Reviewer stance: Jane-Street-style PM asked "would I fund this?" Answer today: **no family in this repo has a demonstrated,
non-artifact, fee-positive edge.** The one family with a hindcast edge (S7 crypto) rests on a one-minute lookahead bug; the
verifier family (weather J1) finds determined states the book has already priced; the maker family (S1) is pre-registered on
n≈30 bins from a two-week trending sample and can earn at most ~$1 per fill. Everything below is ordered so a developer can
attack the P0s first. Probes were run read-only from `D:/prediction-hft` (no code modified).

Severity: **P0** = invalidates the family's evidence or its P&L; **P1** = material P&L leak / wrong decision; **P2** = reduces
edge or slows learning; **P3** = hygiene.
