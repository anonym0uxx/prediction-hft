## P20 — Robust bet acceptance gate for the final-minute rule (registered 2026-10-27 22:10 PT; docs/ROBUST_BETTING_2026-10-27.md; code src/predhft/bet_gate.py; P20_T0 = first close after the s7p13-KX*15M runners restart with --bet-gate)
