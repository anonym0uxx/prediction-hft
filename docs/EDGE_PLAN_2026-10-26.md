## C. PORTFOLIO + SIZING POLICY ($250 paper → real)

### C1. Edge shrinkage and Kelly fraction per family
Per family f, measured mean edge ē (c/ct), clustered se, n clusters. Posterior edge with a zero-mean prior of sd τ = 3c:
`e* = ē · τ² / (τ² + se²)`;  `se* = se · τ / sqrt(τ² + se²)`.
- Trade only if `e* − 1.96·se* > 0` (same as PREREG pass).
- Kelly fraction k_f = 0.25 × min(1, e*/ (2·se*))  → quarter-Kelly only when the edge is ≥ 2σ; half of that at 1–2σ; zero below (scored-only).
- Stake per contract-dollar: `B · k_f · (p* − c)/(1 − c)` with p* = c + e* (do not use the model's raw p). Example today: S7 σ-lo e*=11.3·9/(9+28)=2.7c, se*=5.3·3/√37=2.6c → 2.7−5.1 < 0 → **scored-only**. Correct outcome: no family earns a stake today.

### C2. Drawdown targets (fractional-Kelly ruin bound P(hit x·B) = x^(2/k − 1))
| k | P(−20%) | P(−50%) |
|---|---|---|
| 0.25 | 0.21 | 0.008 |
| 0.125 | 0.03 | 0.00003 |
Target: ≤ 20% family drawdown probability 5% → k ≤ 0.125 until a family has ≥ 2× n_required; k = 0.25 thereafter. Hard halts (keep risk.py): $25/day global (10%), $50/week, $15/family/day; add **$20 per asset-hour across BTC/ETH/SOL combined** (they are one bet: same-minute returns ρ ≈ 0.6–0.8 → effective n ≈ 1.4, so the current per-settlement-ts cap of $20 per ticker is 3× too loose) and **$30 per weather event-date across all cities** (synoptic correlation; already in CFG).
